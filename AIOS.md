# AIOS.md

## Project Name
NutriAI Planner - AI Meal & Nutrition Operating System

## Project Overview
Build a simple AI Operating System (AIOS) prototype for a nutrition and meal planning business. The application should help users manage meal plans, nutrition goals, dietary insights, and health progress from a centralized dashboard.

Generate realistic sample data, meal plans, nutrition information, charts, images, and assets for demonstration purposes.

Keep the application beginner-friendly, visually appealing, and suitable for showcasing as a prototype.

## Screens

### 1. Dashboard
Provide a centralized overview containing:
- Daily calorie summary
- Nutrition statistics
- Health goal progress
- Meal completion status
- Quick insights cards
- Health analytics charts

### 2. AI Meal Planner
Allow users to:
- Select dietary preferences
- Select health goals
- Generate meal recommendations
- View daily meal schedules
- View breakfast, lunch, dinner, and snack suggestions

### 3. Nutrition Insights
Display:
- Calories consumed
- Protein tracking
- Carbohydrate tracking
- Fat tracking
- Nutrition breakdown charts
- AI-generated dietary recommendations

### 4. Health Goals & Progress
Allow users to:
- View health goals
- Track progress
- Monitor weekly performance
- View wellness insights
- Receive AI-generated improvement suggestions

## Navigation
Provide simple navigation using:
- Dashboard
- Meal Planner
- Nutrition Insights
- Health Goals

Include smooth page transitions and responsive layouts.

## Design Requirements

Create a premium modern user experience featuring:
- Beautiful gradients
- Glassmorphism effects
- Rounded cards
- Soft shadows
- Clean layouts
- Interactive charts
- Responsive design
- Mobile-friendly interface
- Smooth animations
- Hover effects
- Consistent visual branding

Use Lucide React icons throughout the application.

Generate custom nutrition-related images, healthy food visuals, recipe banners, and wellness graphics using AI image generation tools where available.

Make every screen visually unique while maintaining a consistent design system.

## Development Requirements

- Maximum 4 screens
- Functional interactive prototype
- No authentication required
- No real database required
- No external integrations required
- No working automations required
- Generate realistic sample data internally
- Generate all required images and assets automatically

## Netlify Deployment Requirements

Ensure compatibility with free Netlify hosting.

All generated images must:
- Be stored in `/public/images/`
- Be referenced using `/images/filename.ext`
- Be included in production builds
- Be copied correctly into `dist/images/`

Ensure all images display correctly after Netlify deployment.

## Final Goal

Create a visually impressive AI Meal & Nutrition Operating System prototype that demonstrates meal planning, nutrition tracking, health insights, and wellness goal management through a modern AI-powered dashboard experience.
